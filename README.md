# Minions: Scarlet's Wrath
## Nomes
- Breno Henrique da Silva Souza
- Vinicius Gabriel Almeida da Silva

## Tema do Jogo
Jogo de aventura 3D com elementos de plataforma e combate baseado no clímax do filme Minions de 2015. O jogo se baseia na questão do jogador poder controlar os três minions principais (Kevin, Stuart e Bob, não ao mesmo tempo, porém alternando entre eles através de um botão).
